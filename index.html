Agent Setup Guide

One-time configuration steps to get the full automated system running

📅
Calendar Consolidation: All calendars flow into one Google account. The agent reads only Google Calendar — one connection covers everything.
1
Sync Outlook 365 → Google Calendar
Publish your work calendar as a live ICS feed. Google subscribes and auto-refreshes every 8–24 hours. Free, native, zero third-party tools needed.
1. Go to outlook.office.com 2. Settings (gear) → Calendar → Shared Calendars 3. Under "Publish a Calendar" → select your work calendar 4. Set to: "Can view all details" → Click Publish 5. Copy the ICS link (NOT the HTML link) 6. Open Google Calendar → Settings → Add Calendar → From URL 7. Paste ICS link → Name it "Work — Outlook" → Add Calendar
Tip: Repeat this for any other calendars (kids school, family shared, etc.) using the same "From URL" method in Google Calendar.
2
Create "Weekly Menu" Google Calendar
The agent writes dinner events here — isolated from your work and personal calendars. Skylight syncs it automatically.
1. Open Google Calendar → + Other Calendars → Create new calendar 2. Name: "Weekly Menu" 3. Color: Choose something distinct (orange or red works well) 4. Click "Create Calendar" 5. Open Skylight app → Settings → Sync Calendars → confirm "Weekly Menu" appears
3
Upload Nutrition Reference to Google Drive
This is the file the agent reads every Friday. Upload once, never re-explain your macros again.
1. Download "nutrition-reference.md" from this dashboard 2. Go to drive.google.com 3. Upload the file → right-click → Open with Google Docs (This converts it to a native Google Doc the agent can read) 4. Name it: "MAXWELL_AGENT_NUTRITION_REF" 5. Copy the Doc URL — you'll need it for Make.com setup
Token savings: This single doc replaces ~3,000 tokens of context per weekly run. At Claude API pricing, that saves ~$0.50–2.00/month.
4
Create Make.com Account & Connect Google
Free account covers your weekly usage (1,000 ops/month). This is your automation backbone.
1. Go to make.com → Sign up free 2. Dashboard → Connections → Google Drive → Connect (Authorize with the same Google account as your calendar) 3. Connections → Google Calendar → Connect 4. Connections → HTTP → No setup needed (used for Claude API calls) 5. Keep your Anthropic API key ready (console.anthropic.com)
5
Install HEB Grocery Agent Chrome Extension
This handles automated cart building on HEB.com without any coding. Claude in Chrome orchestrates it.
1. In Chrome, go to: Chrome Web Store Search: "HEB Grocery Agent" 2. Install extension → pin it to toolbar 3. Go to heb.com → sign into your account 4. Click the extension icon → confirm it shows your account 5. Test: type one item → click "Start Shopping" → confirm it adds to cart 6. Clear the test item before your first real run
Note: This uses unofficial HEB browser automation. HEB may update their site — if the extension stops working, the fallback is Claude in Chrome's built-in browser tools.
6
Deploy This Dashboard to Netlify
Host this file as a live URL so the agent can update it and you can access it from any device.
1. Go to netlify.com → Sign up free 2. From the dashboard: "Add new site" → "Deploy manually" 3. Drag the index.html file into the deploy drop zone 4. Netlify generates a URL: e.g., maxwell-kitchen.netlify.app 5. Optional: Add custom domain under Site Settings → Domain Management 6. Bookmark the URL on your phone — this is your weekly command center
7
Make.com — Scenario 1: Friday Agent Run
This scenario triggers every Friday at noon, reads your nutrition doc + calendar, generates recipes, and updates the dashboard.
Trigger: Schedule → Every Friday at 12:00 PM Step 1 — Google Drive: Get File Content → File: "MAXWELL_AGENT_NUTRITION_REF" Step 2 — Google Calendar: List Events → Calendar: All calendars → Date range: Today + 14 days → Filter: Include travel flags, evening events Step 3 — HTTP: POST to Anthropic API → URL: https://api.anthropic.com/v1/messages → Headers: x-api-key: [YOUR_API_KEY] anthropic-version: 2023-06-01 → Body: { "model": "claude-sonnet-4-20250514", "max_tokens": 4000, "system": "You are the Maxwell family meal planning agent. Read the nutrition reference and calendar data provided. Generate 5 macro-compliant dinner recipes for the week. Output valid JSON only.", "messages": [{"role": "user", "content": "[NUTRITION_DOC] + [CALENDAR_EVENTS]"}] } Step 4 — Netlify: Deploy updated index.html → Method: POST to Netlify Deploy URL → Body: Updated HTML with new recipes injected
Tip: Request full instructions for this Make.com scenario build from Claude — it will generate the exact module configuration for you to copy in.
8
Make.com — Scenario 2: Saturday Cart Build
Triggers Saturday morning after you've selected your recipes. Finalizes the grocery list and hands off to Claude in Chrome + HEB extension.
Trigger: Schedule → Every Saturday at 9:00 AM Step 1 — HTTP: GET selected recipes from dashboard data Step 2 — HTTP: POST to Anthropic API → Generate finalized HEB grocery list JSON → Exclude Costco staples → Group by: Produce, Protein, Dairy, Pantry Step 3 — Claude in Chrome: → Open heb.com (signed in) → Activate HEB Grocery Agent extension → Paste finalized list → Click "Start Shopping" — items added to cart automatically Step 4 — Google Calendar: Create Events → Calendar: "Weekly Menu" → Create 1 event per dinner (Mon–Sun) → Event title: [Meal Name] — [Prep Time] → Description: Link to recipe card on dashboard
